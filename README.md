# TaskFlow

シンプルで使いやすいタスク管理Webアプリです。

## アプリURL

https://mocyo1104.github.io/taskflow/

## 概要

日々のタスクを登録・管理できるWebアプリケーションです。

## 使用技術

- HTML
- CSS
- JavaScript
- LocalStorage

## 実装機能

- タスクの追加
- タスクの完了・未完了の切り替え
- タスクの削除
- LocalStorageによるデータ保存
- ページ再読み込み後のデータ復元

## 工夫したポイント

ブラウザのLocalStorageを利用することで、サーバーやデータベースを用意せずにタスク情報を保存できるようにしました。

## 今後の改善予定

- タスクの編集機能
- 期限設定機能
- 優先度による分類
- スマートフォンへの対応強化
